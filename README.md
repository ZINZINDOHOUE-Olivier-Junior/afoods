# Afoods

Application web de restaurant de cuisine saine : carte des plats, panier, et planificateur de menu du jour ou de la semaine selon le régime et les calories.

Site statique (HTML, CSS, JavaScript), sans installation : ouvrir `index.html` dans un navigateur.

## Fonctionnalités
- Carte filtrable (petit-déjeuner, déjeuner, dîner, vegan, protéines, léger)
- Panier (conservé dans le navigateur)
- Planificateur : un jour ou une semaine, régime, calories par jour, échange d'un plat en un clic
